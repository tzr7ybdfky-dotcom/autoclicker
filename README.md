# AutoClicker

Десктопный автокликер для **macOS** (Apple Silicon и Intel, macOS 13+) и **Windows 10/11 x64**.
Python 3.12 + PySide6, нативная эмуляция мыши и глобальные горячие клавиши через API каждой ОС.
Без браузера, Electron, сервера, аккаунтов, сетевых запросов и телеметрии.

- macOS: мышь — Quartz `CGEventPost`, клавиатура — `CGEventTap` в режиме «только чтение».
- Windows: мышь — `SendInput`/`SetCursorPos`, клавиатура — хук `WH_KEYBOARD_LL`.

Общей библиотеки «на обе ОС» нет: у систем разные разрешения, координаты и ограничения,
поэтому для каждой написан свой адаптер (`autoclicker/platform/macos.py`, `windows.py`).

## Возможности

- Скорость задаётся **интервалом** 10–60 000 мс (от начала одного нажатия до начала
  следующего) или **частотой** 0,016667–100 кликов/с; частота = 1000 / интервал.
  Интервал — основной параметр и хранится без округления (3 клика/с = 333,333… мс).
  Пресеты: 1, 5, 10, 20, 50 кликов/с. По умолчанию — 100 мс (10 кликов/с).
- **Длительность нажатия** 1–59 999 мс, минимум на 1 мс меньше интервала (по умолчанию 20 мс).
- Неверные значения не исправляются молча: ошибка показывается у поля, запуск блокируется.
- Кнопка: левая, правая, средняя.
- Позиция: текущая позиция курсора (курсор не двигается) или фиксированная точка
  (курсор переводится в неё перед каждым нажатием). «Выбрать точку» запоминает позицию
  через 3 с без клика, Esc — отмена. Несколько мониторов и отрицательные координаты поддерживаются.
- Задержка старта 0–30 с с видимым отсчётом (по умолчанию 3 с).
- Завершение: вручную, после N кликов (1–1 000 000) или через время (от 1 с до 24 ч).
- Одно глобальное сочетание «Старт/Стоп» (по умолчанию **Ctrl + Alt + F8**, на Mac —
  **Control + Option + F8**), назначается кнопкой «Назначить».
- Аварийная остановка: **Esc** или курсор в **левый верхний угол основного экрана (5×5 точек)**.
- Счётчик кликов, время работы, статусы «Остановлен», «Ожидание старта», «Работает»,
  «Нет разрешений», «Ошибка».
- Настройки и положение окна сохраняются; повреждённый файл не мешает запуску.
  Приложение никогда не начинает кликать само после открытия.

## Запуск из исходников

Нужен Python 3.12 (python.org). На macOS лучше universal2-установщик с python.org.

> Если папка проекта лежит в синхронизируемой с iCloud папке (Рабочий стол, Документы),
> **не называйте окружение `.venv`**: iCloud помечает содержимое папок с точкой в имени
> флагом «скрытый», и Qt перестаёт находить свои плагины (ошибка
> `Could not find the Qt platform plugin "cocoa"`). Используйте имя `venv`, как ниже.

### macOS

```bash
cd autoclicker
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m autoclicker
```

### Windows (PowerShell)

```powershell
cd autoclicker
py -3.12 -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe -m autoclicker
```

Для запуска без окна консоли используйте `venv\Scripts\pythonw.exe -m autoclicker`.

## Разрешения macOS

Нужны два разрешения в **«Системные настройки → Конфиденциальность и безопасность»**:

| Раздел | Зачем |
|---|---|
| **Универсальный доступ** | отправлять клики в другие приложения |
| **Мониторинг ввода** | глобальное сочетание «Старт/Стоп» и Esc |

Запись экрана **не нужна** и не запрашивается. Приложение проверяет разрешения системными
вызовами (`CGPreflightPostEventAccess`, `CGPreflightListenEventAccess`). Кнопки
«Открыть настройки» в окне показывают системный запрос и открывают нужный раздел.
Без «Универсального доступа» запуск не выполняется, статус — «Нет разрешений»: macOS
молча выбрасывает клики без этого разрешения, и приложение не показывает ложное «Работает».
Если разрешение отозвать во время работы, клики останавливаются со статусом «Ошибка».

**Из исходников и из сборки разрешения выдаются разным программам:**

- **из исходников** macOS спрашивает разрешение у программы, из которой запущен Python:
  Терминал, iTerm, VS Code и т. п. Включите в обоих разделах именно её;
- **сборка `AutoClicker.app`** — включите сам `AutoClicker`.

После выдачи разрешения перезапустите приложение. Разрешения macOS привязаны к подписи
программы: после каждой пересборки ad-hoc-подписанного `.app` система считает его новым —
удалите старую запись кнопкой «−» и добавьте приложение заново.

Если на левый верхний угол назначен «Активный угол» (Системные настройки → Рабочий стол
и Dock → Активные углы), он тоже сработает при аварийной остановке.

Когда активно поле ввода пароля или в терминале включён «Защищённый ввод с клавиатуры»,
macOS скрывает нажатия от всех слушателей: горячая клавиша и Esc в этот момент не сработают.
Угол экрана и кнопка «Стоп» работают всегда.

## Windows: ограничения

- Права администратора не нужны и не запрашиваются; UAC приложение не обходит.
- Из-за **UIPI** клики не доходят до окон, запущенных от имени администратора, и до
  защищённых окон (запрос UAC, экран блокировки, Ctrl+Alt+Del). Windows не сообщает
  о такой блокировке: счётчик растёт, а окно клики не получает.
- По той же причине, пока активно окно администратора, Windows не передаёт приложению
  его клавиши: горячая клавиша и Esc там не сработают. Угол экрана и кнопка «Стоп»
  работают всегда.
- Координаты — физические пиксели виртуального рабочего стола (Per-Monitor DPI v2),
  поэтому точки корректны при любом масштабе (100–300 %) и на нескольких мониторах.
  Угол аварийной остановки — 5×5 логических пикселей, переведённых по масштабу основного монитора.
- Если выбранное сочетание уже зарегистрировано другой программой через `RegisterHotKey`,
  приложение предупредит. Конфликты, которые Windows не показывает, обнаружить нельзя.

## Важно знать

- **Точность** зависит от ОС, загрузки процессора и энергосбережения. Движок планирует
  клики по монотонным часам от начала нажатий и не копит погрешность. Если система
  задержала поток, опоздавшие клики **пропускаются**, а не отправляются пачкой.
  На Windows на время работы включается таймер 1 мс (`timeBeginPeriod`) и отключается
  замедление фоновых процессов. На macOS на это время отключается App Nap.
- **Esc и сочетание не перехватываются**: их получит и активное приложение.
- Работа в играх не гарантируется. Функций обхода античит-систем нет и не будет.
- Свёрнутое окно продолжает работать; закрытие окна останавливает клики, отпускает
  кнопку и завершает приложение.

## Где хранятся настройки

JSON-файл `settings.json` в стандартной папке настроек пользователя:

- macOS: `~/Library/Preferences/AutoClicker/settings.json`
- Windows: `%LOCALAPPDATA%\AutoClicker\settings.json`

Чтобы сбросить настройки, удалите этот файл.

## Сборка

Собирать нужно **на той ОС, для которой нужна сборка**: PyInstaller не делает
кросс-компиляцию. `.exe` собирается на Windows, `.app` — на Mac.

### macOS → `dist/AutoClicker.app`

```bash
packaging/build_macos.sh              # архитектура текущего Python
packaging/build_macos.sh arm64        # только Apple Silicon
packaging/build_macos.sh x86_64       # только Intel
packaging/build_macos.sh universal2   # один .app для Apple Silicon и Intel
```

Скрипт создаёт `build/venv-macos`, ставит зависимости, запускает тесты, собирает `.app`
без консоли во временной папке, проверяет подпись и запускает `--smoke-test` (без кликов,
окон и глобального слушателя; для universal2 — и x86_64-часть через Rosetta, если она
установлена), затем копирует `.app` в `dist/`.

Установка в «Программы»:

```bash
ditto --noextattr --norsrc dist/AutoClicker.app /Applications/AutoClicker.app
```

Если проект лежит в папке, синхронизируемой с iCloud, iCloud добавляет к `dist/AutoClicker.app`
служебные атрибуты Finder. Приложение запускается, но `codesign --verify --strict` на эту
копию жалуется. Копия, сделанная командой выше, проходит проверку без ошибок. По этой же
причине сборка и подпись выполняются во временной папке, а не в `dist/`.

- `x86_64` и `universal2` требуют universal2-Python с python.org: укажите его так:
  `PYTHON=/Library/Frameworks/Python.framework/Versions/3.12/bin/python3.12 packaging/build_macos.sh universal2`.
  Python из Homebrew обычно одноархитектурный.
- `universal2` возможен, потому что все бинарные зависимости (PySide6-Essentials 6.11.2,
  shiboken6, pyobjc 12.2.2) выпускаются в universal2-сборках. Если обновите зависимости
  и это изменится, собирайте `arm64` и `x86_64` отдельно.
- PySide6 6.11 — последняя ветка с поддержкой macOS 13; минимальная версия в сборке — 13.0.

### Windows → `dist\AutoClicker\AutoClicker.exe`

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1
```

Нужен 64-битный Python 3.12 (`py -3.12`) или путь в `$env:PYTHON`. Скрипт создаёт
`build\venv-windows`, запускает тесты, собирает приложение без консоли (папка
`dist\AutoClicker`, распространять её целиком) и проверяет `--smoke-test`.
`-ExecutionPolicy Bypass` действует только на этот запуск и не меняет политику системы.

### Подпись

- **macOS.** PyInstaller подписывает `.app` ad-hoc-подписью: этого достаточно, чтобы
  запускать приложение на том Mac, где оно собрано. Для передачи на другие Mac нужна
  подпись сертификатом Developer ID и нотаризация Apple, иначе Gatekeeper не даст открыть
  приложение двойным щелчком:
  ```bash
  AUTOCLICKER_CODESIGN_IDENTITY="Developer ID Application: Имя (TEAMID)" packaging/build_macos.sh universal2
  ditto -c -k --keepParent dist/AutoClicker.app AutoClicker.zip
  xcrun notarytool submit AutoClicker.zip --keychain-profile <профиль> --wait
  xcrun stapler staple dist/AutoClicker.app
  ```
- **Windows.** Неподписанный `.exe` вызывает предупреждение SmartScreen. Для
  распространения подпишите его сертификатом подписи кода:
  `signtool sign /fd SHA256 /tr <TSA-URL> /td SHA256 /a dist\AutoClicker\AutoClicker.exe`.
  Отключать SmartScreen, Gatekeeper или антивирус не нужно и не рекомендуется.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты используют подставной адаптер мыши и **не отправляют реальных кликов**. GUI-тесты
работают в режиме `offscreen`. Проверяется:

- ровно N кликов и порядок down/up, выбранная кнопка;
- остановка во время удержания, во время длинного интервала и во время задержки старта;
- остановка по времени с немедленным отпусканием кнопки; время идёт после задержки;
- отпускание кнопки после ошибки (при нажатии и во время удержания);
- защита от второго рабочего потока при повторном «Старт»;
- отсутствие «догоняющей» серии после задержки ОС; планирование по началу нажатий;
- защитный угол (в удержании, ожидании и задержке старта), отключённый монитор;
- валидация несовместимых значений и диапазонов, точные пересчёты интервала и частоты;
- горячие клавиши: подавление автоповтора удерживаемой клавиши, повтор только после
  отпускания, точное совпадение модификаторов, Esc, режим назначения, замена сочетания;
- сохранение настроек и устойчивость к повреждённому файлу;
- раскладка структур WinAPI (`INPUT` = 40 байт и т. д.), таблицы клавиш;
- окно: значения по умолчанию, блокировка запуска, «Стоп» во время работы, сохранение при закрытии.

## Ручной чек-лист

Выполнить на каждой ОС на реальном рабочем столе (лучше в текстовом редакторе
или на странице-счётчике кликов).

**Общее (macOS и Windows)**

- [ ] После запуска приложение не кликает; статус «Остановлен» (или «Нет разрешений» на Mac без разрешения).
- [ ] Старт с задержкой 3 с: виден отсчёт и статус «Ожидание старта», затем «Работает»; первый клик сразу после отсчёта.
- [ ] 10 кликов/с: счётчик растёт примерно на 10 в секунду; отдельно проверить 1, 50 и 100 кликов/с.
- [ ] Левая, правая (контекстное меню) и средняя кнопка работают в другом приложении.
- [ ] «Текущая позиция»: курсор не двигается сам, клики идут туда, где он находится.
- [ ] «Фиксированная точка»: «Выбрать точку» → 3 с → координаты заполнены без клика; Esc во время отсчёта отменяет выбор.
- [ ] Точка на втором мониторе, в том числе левее/выше основного (отрицательные координаты).
- [ ] Отключить монитор с выбранной точкой → при старте понятная ошибка у координат.
- [ ] Точку в углу 5×5 сохранить нельзя (ошибка у поля).
- [ ] «После N кликов» (например, 25): ровно 25 кликов, затем «Остановлен».
- [ ] «По времени» 10 с с нажатием 5 000 мс и интервалом 60 000 мс: кнопка отпускается ровно через 10 с.
- [ ] Ctrl/Control + Alt/Option + F8 в другом приложении запускает и останавливает; удержание сочетания не переключает многократно.
- [ ] Esc в другом приложении — аварийная остановка; Esc получает и само приложение.
- [ ] Курсор в левый верхний угол основного экрана — остановка (и во время длинного удержания).
- [ ] «Назначить»: новое сочетание работает, старое — нет; Esc отменяет назначение; Esc назначить нельзя; во время назначения автокликер не запускается.
- [ ] Во время работы все настройки заблокированы, «Стоп» доступен.
- [ ] Свернуть окно во время работы — клики продолжаются; закрыть окно во время удержания — кнопка отпущена, процесс завершён.
- [ ] Перезапуск: настройки, сочетание, размер и положение окна восстановлены.
- [ ] Масштабирование: окно читаемо на Retina и при масштабе Windows 125/150/200 %; окно можно увеличить.

**Только macOS**

- [ ] Без «Универсального доступа»: «Нет разрешений», старт не выполняется, кнопка «Открыть настройки» ведёт в нужный раздел.
- [ ] Без «Мониторинга ввода»: клики работают, глобальные клавиши — нет, это видно в окне.
- [ ] Запуск из исходников: разрешения нужны Терминалу (или другой программе-родителю).
- [ ] Сборка `.app` на Apple Silicon; на Intel-Mac (или через Rosetta для universal2).
- [ ] Отзыв «Универсального доступа» во время работы → остановка со статусом «Ошибка».
- [ ] Сочетание срабатывает с F8 и как F8, и как Fn + F8 (зависит от настройки клавиатуры).

**Только Windows**

- [ ] Работает без прав администратора; UAC не запрашивается.
- [ ] Окно, запущенное от имени администратора, клики не получает (ожидаемое ограничение UIPI); приложение не зависает.
- [ ] Сочетание, занятое другой программой, вызывает предупреждение при назначении.
- [ ] Мониторы с разным масштабом: «Выбрать точку» и клики попадают точно.
- [ ] `AutoClicker.exe` запускается без окна консоли; SmartScreen для неподписанной сборки — ожидаемо.

## Структура

```
autoclicker/
  model.py          настройки, пересчёт интервала/частоты, валидация
  engine.py         рабочий поток кликов (планирование, остановка, отпускание)
  hotkeys.py        разбор глобальных клавиш, режим назначения, мост в Qt
  storage.py        сохранение настроек (JSON, атомарная запись)
  app.py            точка входа, --smoke-test
  platform/
    base.py         протоколы адаптеров и разрешений
    macos.py        Quartz: CGEvent, CGEventTap, разрешения, App Nap
    windows.py      WinAPI: SendInput, WH_KEYBOARD_LL, DPI, таймер
    keymaps.py      коды клавиш macOS/Windows и подписи
  gui/
    main_window.py  окно
    widgets.py      числовые поля с −/+, сегменты, карточки
    keys.py         клавиши Qt → канонические (запасной путь)
    theme.py        тёмная тема с одним акцентом
    icon.py         иконка, нарисованная кодом
packaging/          spec PyInstaller, скрипты сборки, генератор иконок
tests/              pytest (без реальных кликов)
```
